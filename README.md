# MDesign Projects · Updates

This public repository only hosts signed Android APK release assets and the small update manifest used by MDesign Projects. The application source and development history are maintained in a separate private repository.

Download releases only through the MDesign app or from the [Releases page](https://github.com/Kurono-M/MDesign-Projects-Releases/releases). Android verifies the package name, version, SHA-256 and signing certificate before showing its installer.

The APK is distributed for direct installation outside Google Play. Android asks the device owner to approve each installation.
